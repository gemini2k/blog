SQLD와 SQLP, 두 SQL 자격은 무엇이 다른가

GEMINI2K·2026년 11월 14일

SQL을 다루는 자격으로 SQLD와 SQLP가 함께 거론되지만, 두 자격은 난이도만 다른 것이 아니라 시험 구성과 응시 조건, 합격 절차가 다르다. 한국데이터산업진흥원(dataq.or.kr)의 공식 안내를 기준으로 차이를 정리했다.

두 자격의 위치

SQLD(SQL 개발자)와 SQLP(SQL 전문가)는 모두 「자격기본법」 제17조에 따라 등록된 민간자격으로, 국가공인을 받았다(공인자격 제2022-04호). 시행 기관은 한국데이터산업진흥원이다.

공식 정의로 보면 SQLD는 데이터베이스와 데이터 모델링 지식을 바탕으로 응용 소프트웨어를 개발하면서 정확하고 성능 좋은 SQL을 작성하는 개발자를 대상으로 한다. SQLP는 여기에 더해 SQL 실행 구조, 인덱스·조인 튜닝, Lock과 트랜잭션 동시성 제어 같은 내부 동작을 이해하고 SQL을 튜닝하는 역할까지 다룬다.

시험 구성 비교

구분 SQLD SQLP
과목 데이터 모델링의 이해, SQL 기본 및 활용 (2과목) 위 2과목 + SQL 고급활용 및 튜닝 (3과목)
문항 수 객관식 50문항 72문항 (객관식 70 + 실기 2)
배점 문항당 2점, 100점 객관식 70점 + 실기 30점(문항당 15점)
시험 시간 90분 180분
시행 횟수 연 4회 연 2회

SQLD의 과목 비중은 데이터 모델링의 이해 10문항, SQL 기본 및 활용 40문항이다. 모델링 과목은 엔터티·속성·관계·식별자, 정규화, 관계와 조인, 트랜잭션, Null, 본질식별자와 인조식별자를 다루고, SQL 과목은 SELECT·함수·WHERE·GROUP BY·ORDER BY·조인부터 서브쿼리와 집합 연산자까지 이어진다.

SQLP는 모델링 10문항, SQL 기본 및 활용 20문항, SQL 고급활용 및 튜닝 40문항으로 튜닝 비중이 가장 크다. 실기 2문항은 필기시험 안에 포함되어 함께 치른다.

응시자격과 합격 기준

SQLD는 응시자격에 제한이 없다. 합격 기준은 총점 60점 이상이며, 과목별 40% 미만이면 과락이다.

SQLP는 시험일 이전에 다음 중 하나를 충족해야 한다.

  • 학력·경력: 학사학위 이상, 전문학사 취득 후 실무경력 2년 이상, 고등학교 졸업 후 실무경력 4년 이상
  • 자격 보유: SQLD, 데이터아키텍처 전문가(DAP)·준전문가(DAsP), IBM·Microsoft·Oracle·Sybase가 인증하는 데이터베이스 관련 자격

SQLP의 시험 합격 기준은 총점 75점 이상(과목별 40% 미만 과락)이다. 다만 시험에 붙었다고 끝이 아니라, 합격자가 응시자격 증빙서류(경력·재직증명서, 최종학력증명서, 자격증 사본 중 해당 서류)를 내고 심의를 통과해야 최종 합격이 된다. SQLD는 필기 합격이 곧 최종 합격이다.

두 자격 모두 유효기간은 합격일로부터 2년이고, 보수교육을 이수하면 영구 자격으로 전환된다.

학점 인정

「학점인정 등에 관한 법률」에 따라 자격 취득과 그에 필요한 교육과정 이수를 학점은행제 학점으로 인정받을 수 있다. SQLD는 6학점, SQLP는 12학점이다.

어떤 순서로 준비할까

SQL을 실무에서 쓰기 시작했다면 SQLD가 자연스러운 출발점이다. 응시 제한이 없고, 모델링과 SQL 문법이라는 공통 기반을 검증한다. SQLD를 취득하면 SQLP 응시자격(자격 보유 기준)도 함께 갖추게 된다.

SQLP는 운영 중인 시스템의 느린 쿼리를 분석하고 실행계획을 손보는 역할을 맡았거나 맡을 예정일 때 의미가 크다. 시험의 절반 이상이 튜닝 과목이고 실기 문항이 30점을 차지하므로, 문법 암기보다 실행계획을 직접 읽고 고쳐 본 경험이 준비의 중심이 되어야 한다. 시행이 연 2회뿐이라 일정을 미리 잡아 두는 것도 중요하다.
